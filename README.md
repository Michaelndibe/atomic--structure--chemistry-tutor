# Atomic Structure Chemistry Tutor & Assessment System

A portfolio project by **Michael Ndibe Chekwube** demonstrating Chemistry subject-matter expertise, educational technology, assessment design, scientific reasoning, and basic Python application development.

## What the application does

- Teaches core atomic-structure concepts.
- Lets users change proton, neutron, and electron counts.
- Calculates atomic number, mass number, and net charge.
- Provides an interactive multiple-choice quiz with explanations and scoring.
- Evaluates short Chemistry answers against transparent scientific rubrics.
- Includes documentation suitable for a professional portfolio.

## Technology

- Python
- Streamlit

## Run locally

1. Install Python 3.10 or newer.
2. Open a terminal in this folder.
3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Start the application:

```bash
streamlit run app.py
```
